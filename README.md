This project demonstrates a folder-based ingestion pattern for bakery sales, payments, products, customers, and expense data. The analytics model loads daily and monthly CSV snapshots from a structured source folder, applies the same cleaning and transformation logic to each dataset, and exposes a business reporting layer in Power BI.
